# 순기 식단 (順氣)

사상체질·자율신경 연동형 맞춤 식단·라이프스타일 웹앱.
기본 프로필은 **소음인 · 기체증(명치 막힘) · 부교감 저하 · 양약 복용 · 회사 아침/점심 · 야식 잦음**.

| 화면 | 하는 일 |
|---|---|
| 오늘 식단 | ① 아침 ② 점심에 먹은 반찬을 적으면 끼니별 평가(좋은 한 끼·무난·부담될 수 있는 한 끼)와 반찬별 한 줄 이유가 나온다. ③ 그 결과로 저녁을 정한다: "찬 음식과 기름진 반찬을 드셨어요 → 따뜻한 국물과 담백한 생선·두부로" 같은 이유, 양(가볍게·평소·든든하게), 추천 조합 3개. 끼니를 거르면 저녁을 든든하게 안내한다. 먹기 전에는 ‘메뉴판으로 골라 보기’(식판)로 담을 것·거를 것을 미리 가를 수 있다 |
| 야식 | 밤에 배고플 때 따뜻한 차 + 15분 → 가짜 배고픔 6문항 → 가벼운 대체식 |
| 설정 | **내 설정**(체질·식사 환경·시각), **약**(약 이름 → 약별 금기 음식, 복약 시계), **기록**(컨디션 기록과 14일 추이), **알림·백업**(캘린더 .ics, 앱 알림, 홈 화면 설치, JSON 백업·복원) |

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 규칙 엔진·식단 흐름 테스트 99개
npm run build      # dist/
npm run build:artifact   # claude.ai Artifact용 단일 HTML 조각 → dist-artifact/sungi-artifact.html
```

기술 스택: Vite 6 · React 18 · TypeScript 5 (strict) · Vitest 3. 런타임 의존성은 React뿐이다.
기록은 브라우저 localStorage에 저장된다 (`src/infra/storage.ts`의 저장소 포트로 교체 가능).

## 구조와 규칙

규칙 엔진 계산식과 확장 방법은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
결정과 스스로 정한 기본값은 [docs/DECISIONS.md](docs/DECISIONS.md),
Claude Code용 개발 프롬프트는 [docs/prompts/sungi-meta-prompt-v2.md](docs/prompts/sungi-meta-prompt-v2.md)에 있다.

**설치·알림:** 휴대폰 브라우저로 배포 주소를 열고 홈 화면에 추가한다(iPhone은 공유 → 홈 화면에 추가). 이 앱은 서버가 없어 앱이 닫혀 있을 땐 스스로 알림을 보낼 수 없으므로, 알림은 ‘내 몸 → 알림·백업’에서 캘린더 파일을 받아 휴대폰 캘린더에 넣는 방식이 가장 확실하다.

## 주의

이 앱은 사상의학 식이 원칙을 생활에 옮기는 도구이며 진료·처방을 대신하지 않는다.
복용 중인 약과 음식의 상호작용은 처방의·약사에게 확인해야 한다.
흉통, 검은 변, 삼킴 곤란, 원인 없는 체중 감소가 있으면 앱이 아니라 병원으로 가야 한다.
